# VOYGR

> Real-world place intelligence for AI apps and agents. VOYGR validates and enriches
> location and point-of-interest data — confirming that a place still exists and is
> still open, detecting relocations, rebrands and closures, and enriching place records
> with foundational, operating and contextual attributes. It also ships a Calls API that
> places real outbound phone calls with an AI voice agent, which is how it reaches the
> businesses that have a phone but no API.

VOYGR is a Y Combinator (W26) and SNR.VC backed seed-stage company in San Francisco,
founded by Vlad Baskakov (CEO, ex-Google Maps) and Yarik Markov (CTO, ex-Google/Meta/Apple).

Two public API surfaces exist, both authenticated with an `X-API-Key` header and both
metered from one credit balance. Keys are self-serve: sign up at
https://api.voygr.tech/checkout and the key is emailed (never shown in the browser or
returned by the API). Credit rates: validation, enrichment, business status and
categorize cost 1 credit per request; an AI booking call costs 10 credits. Credits never
expire.

## APIs

- [Voygr Calls API](https://api.voygr.tech/docs): OpenAPI 3.1.0, 12 operations. Programmatic outbound phone calls executed by an AI voice agent — submit a task, the agent dials, conducts the conversation, and returns a structured outcome with a full transcript.
- [OpenAPI (Calls API)](https://api.voygr.tech/openapi.json): the machine-readable contract, served from the API host root.
- [Voygr Business Validation API](https://github.com/voygr-tech/dev-tools#api-reference): base https://dev.voygr.tech. `POST /v1/business-status` returns existence_status (exists/not_exists/uncertain) and open_closed_status (open/closed/uncertain) for a name+address; `GET /v1/usage` returns quota. Documented in the dev-tools README; not included in the public OpenAPI.

## Calls API operations

- `POST /calls` — place a call. Freeform (`target_phone` + plain-English `brief`) or structured (`intent` + `slots`). Five intents: inquiry, info_gathering, issue_resolution, booking, cancellation. Freeform returns `{"call": {...}}`; structured returns a flat envelope.
- `GET /calls` — list calls (`limit` 1..1000).
- `GET /calls/{call_id}` — poll until `status` is completed, failed or cancelled (typically 30-90s). Terminal response carries `outcome_type`, `outcome_summary`, `transcript_full`.
- `GET /calls/{call_id}/events?after_event_id=N` — cursor-polled, SSE-formatted progress events. Short requests only; the gateway strips `Last-Event-ID`.
- `POST /calls/{call_id}/answer` — answer an `ask_user` question raised mid-call (create the call with `ask_user_mode: "stream"` to receive them).
- `POST /calls/{call_id}/cancel` — cancel a queued or active call. Safe to call idempotently.
- `GET /calls/{call_id}/transcript-merged` — complete two-sided transcript rebuilt from the dual-channel recording, including IVR trees and hold announcements the live pipeline never transcribed. `202 {"status":"merger_pending"}` means the merge has not finished.
- `POST /calls/{call_id}/transcript-merged/rebuild` — force the rebuild. Idempotent; costs a full transcription pass.
- `GET /skills` and `GET /skills/{skill_id}/manifest` — VOYGR's own intent registry and slot schemas. This is not MCP.
- `GET /users/me` — customer identity, credit balance, held credits, concurrency cap.
- `GET /v1/usage` — `available` (spendable now) and `call_credit_hold` (what one call freezes).
- `GET /health` — unauthenticated liveness check.

## Agent surface

- [callwright skill](https://github.com/voygr-tech/callwright-skill): VOYGR's own packaged Agent Skill — `SKILL.md` for Claude Code, `AGENTS.md` for Codex. "Give your agent a phone." MIT licensed.
- No MCP server. `/mcp` 404s on both API hosts and MCP is mentioned nowhere in VOYGR's docs or repos; the intended agent path is the skill over plain REST + curl.
- No A2A agent card. `/.well-known/agent-card.json` and `/.well-known/agent.json` 404 on every host.

## Billing and limits

- Hold at dial time: 30 credits (refundable, not a charge). Charged on a `success_*` outcome: 10 credits. Unsuccessful outcomes (no answer, voicemail, technical): 0.
- `402` when the available balance cannot cover the 30-credit hold.
- Free keys: 5 requests/second, 10 requests/minute, 25 calls/day, 2,500 starting credits. Paid keys: 10 requests/second, 100 requests/minute, 5,000 calls/day. `429` beyond.
- Concurrent calls are capped per key (`409` with `active_call_ids`; typically 2).
- Credit packs (https://api.voygr.tech/checkout/packs): 1,000 credits $10.00, 2,500 credits $24.00, 5,000 credits $45.00. Stripe-hosted payment.
- Maintenance windows return `503` with a `resume_at` timestamp.

## Acceptable use

Calls are transactional and user-initiated only — no telemarketing, solicitation, bulk
dialing or harassment. The agent discloses that it is an AI assistant and that the call
is recorded; disclosure is not configurable. United States destinations only. Recordings
and transcripts are retained for a maximum of 90 days. 13 languages plus `auto`.
